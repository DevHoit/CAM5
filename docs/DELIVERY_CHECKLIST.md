# Lista de aceptación frontend ↔ backend

- [ ] La sesión retorna usuario y rol efectivo.
- [ ] El rol se aplica también en el servidor.
- [ ] El activo, gateway y controlador se cargan desde la API.
- [ ] Canales deshabilitados desaparecen de indicadores y reportes.
- [ ] Valores, unidades, calidad y timestamps coinciden en todos los módulos.
- [ ] Tendencias respetan canal y periodo de la URL.
- [ ] Alarmas mantienen estado después de recargar.
- [ ] Una alarma no crea órdenes duplicadas.
- [ ] Cerrar una alarma exige nota y genera auditoría.
- [ ] Cambios Modbus se validan antes de persistir.
- [ ] Reportes muestran estado de generación y URL de descarga.
- [ ] Notificaciones registran intento, entrega y error.
- [ ] Los errores de red permiten reintentar sin perder formularios.
- [ ] El portal diferencia `stale` de `offline`.
- [ ] Backups, retención y auditoría han sido definidos fuera del frontend.
